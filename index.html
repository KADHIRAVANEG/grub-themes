## Install

Cards show the static 1920×1080 image used by GRUB. GIF motion in source artwork is website-only: standard GRUB themes do not animate backgrounds. The installer backs up /etc/default/grub automatically.

git clone https://github.com/KADHIRAVANEG/grub-themes gorgeous-grub
cd gorgeous-grub
chmod +x install.sh
sudo ./install.sh                # interactive dropdown
sudo ./install.sh miku           # pick directly by slug
sudo ./install.sh -t 10          # set boot timeout to 10 seconds
sudo ./install.sh -t 10 miku     # set timeout AND install theme
sudo ./install.sh -r nimbus      # install rEFInd companion (native horizontal dock)
sudo ./install.sh -l             # list themes
sudo ./install.sh -u             # restore previous config

💡 Note on Bootloader Navigation: GNU GRUB2 natively renders vertical boot menus (↑ / ↓) across all Linux distros, Legacy BIOS, and UEFI. For modern UEFI systems desiring a native horizontal icon dock (← / →), companion rEFInd themes are included for select themes via sudo ./install.sh -r <theme>.
